# 3-minute judge demo

1. Start a fresh session. Introduce ARIA as a 3D companion whose memory records sources.
2. Tell ARIA: “The engineering wing is safe. I checked it.” Show `player_report` / `unverified` in the inspector.
3. Click the sensor console. Show the sensor hazard and the open conflict. Ask “What do you currently believe about the engineering wing, and why?”
4. Attempt entry. Show that the backend blocks it.
5. Click the repair panel. The server records repair and an authoritative normal follow-up reading.
6. Ask ARIA what it believes now. Show the verified memory and resolved conflict.
7. Close with: the LLM proposes dialogue; deterministic backend rules control world state.
